# Spinner

Shows that something is in progress. Without a `label`, it is decorative and
hidden from assistive technologies. With a `label`, it becomes a status region
that screen readers announce.

<Canvas of={SpinnerStories.Default} />

## Usage

<Guidelines>
  <Guideline when="Next to an element that already announces the wait.">
    Without a label, like the spinner inside a pending `Button`.
  </Guideline>
  <Guideline when="For a wait no button carries.">With a label, like an area that loads.</Guideline>
  <Guideline use={ButtonStories} when="When the wait is a button's action running.">
    `pending` on `Button` or `IconButton` shows the spinner and sets `aria-busy`.
  </Guideline>
</Guidelines>

For a progress that can be measured, use the native `<progress>` element.

## Examples

### With a label

`label` turns the spinner into a status region: `label` is announced, the icon
stays hidden.

<Canvas of={SpinnerStories.WithLabel} />

A live region announces what changes after it appears. A spinner mounted with
its label at once may not be announced by every screen reader. This limit is
not covered by a test.

## Edge cases

### Inside a pending button

Without `label`, the spinner stays hidden from assistive technologies: the
button's name and its `aria-busy` say it, and nothing is announced twice.

<Canvas of={SpinnerStories.InsideAPendingButton} />

## Keyboard

None: the spinner is never focusable.

## Accessibility

- `role="status"` is a polite live region: its text is announced without
  interrupting the reader.
- The icon is always hidden from assistive technologies. Only `label` is read.
- `role` and `children` are not props: the role follows `label`.

## API

### Props

The props of a native `<span>`, minus `children` and `role`, plus `icon` and
`label`:

<Controls of={SpinnerStories.Default} />

### Attributes

The attributes the rendered `<span>` carries in each example. An app styles each
state from them, never from a class:

<Attributes stories={[SpinnerStories.Default, SpinnerStories.WithLabel]} />

### Styling

The component has no class and no icon. Each app, in its own
`components/ui/spinner.tsx`:

- passes its loading icon and its animation, inside `motion-safe:`, since
  motion is opt-in;
- gives `label` its look, usually inside an `sr-only` span.

The icon takes `currentColor`, the color of the text around it.
