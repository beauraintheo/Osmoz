# Icon

Renders an icon component so it is either hidden from assistive technologies
or announced as an image with a name. Without a `label`, it is decorative. With a `label`,
it becomes an image that screen readers announce. The app gives it its sizes,
so every icon of the app follows the same scale.

<Canvas of={IconStories.Default} />

## Usage

<Guidelines>
  <Guideline when="Next to a text that already says what the icon means.">
    Decorative, like an icon inside a `Button`.
  </Guideline>
  <Guideline when="When the icon carries a meaning no text repeats.">
    With a `label`, like a warning sign.
  </Guideline>
  <Guideline use={IconButtonStories} when="For an action shown by an icon alone.">
    It names the action, not the image.
  </Guideline>
  <Guideline use={SpinnerStories} when="To show a wait.">
    It becomes a status region when the wait needs announcing.
  </Guideline>
</Guidelines>

## Keyboard

None: the icon is never focusable.

## Accessibility

- A decorative icon is never announced, so a button reads "Save", not "image,
  Save".
- A labeled icon has the `img` role: its content is not read, only `label`.
  The app passes it from its catalog.
- `role`, `aria-hidden` and `aria-label` are not props: they follow `label`.

## API

### Props

The props of a native `<svg>`, minus `aria-hidden`, `aria-label`, `children`
and `role`, plus `icon` and `label`. `icon` is the icon component itself, not
an element: `icon={RiSaveLine}`. The component renders it, with no wrapper,
and passes it every other prop. Any component that accepts the props of an
`<svg>` fits, so the package depends on no icon library.

<Controls of={IconStories.Default} />

### Attributes

The attributes the rendered `<svg>` carries in each example. An app styles each
state from them, never from a class:

<Attributes stories={[IconStories.Default, IconStories.WithLabel]} />

### Styling

The component has no class. Each app, in its own `components/ui/icon.tsx`,
picks its icon library and gives the icon its sizes, one per `size`.

The icon takes `currentColor`, the color of the text around it.
