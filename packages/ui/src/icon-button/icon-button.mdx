# IconButton

A `Button` whose action is shown by an icon alone. It requires a text `label`,
which becomes its accessible name, so a screen reader announces "Undo, button"
and not an unnamed graphic.

<Canvas of={IconButtonStories.Default} />

## Usage

<Guidelines>
  <Guideline when="For a frequent action that its icon makes obvious.">
    Undo, redo, help, reset a property.
  </Guideline>
  <Guideline when="Where space is short.">A toolbar, a row of a list.</Guideline>
  <Guideline use={ButtonStories} when="When the action is not obvious without text.">
    With an `Icon` next to its text.
  </Guideline>
  <Guideline use={LinkStories} when="To go to another page or URL.">
    A button that navigates breaks middle-click, "open in a new tab" and the screen reader's links
    list.
  </Guideline>
</Guidelines>

## Examples

### Disabled

`disabled` removes the button from the tab order and blocks its click.

<Canvas of={IconButtonStories.Disabled} />

### Pending

`pending` sets `aria-busy`, blocks the click and keeps the button focusable.

<Canvas of={IconButtonStories.Pending} />

`IconButton` renders a `Button`, so it has every state of `Button`, including
**disabled but focusable** (`focusableWhenDisabled`), documented on its page.
In every state, the accessible name stays the `label`.

## Edge cases

### The name stays the label

An icon that carries its own name does not change the button's: `label` is
read, while pending too.

<Canvas of={IconButtonStories.NameStaysTheLabel} />

## Keyboard

<Keyboard>
  <Key keys={["Tab"]}>Moves the focus to the button, unless it is `disabled`.</Key>
  <Key keys={["Enter", "Space"]}>Runs the action, unless the button is disabled or pending.</Key>
</Keyboard>

## Accessibility

- The accessible name is `label`, set as `aria-label`. The app passes it from
  its catalog.
- `label` is required and `aria-label` and `children` are not props: the name
  cannot be left out or overridden.
- The icon is never announced: `aria-label` replaces the button's content as
  its name, and a button's content is not read on its own. The app passes a
  decorative `Icon` all the same.

### Styling

The component has no class. Each app styles it in its own
`components/ui/icon-button.tsx`: a square size for the button and its icon, and
the same state classes as `Button`. See each app's section of this Storybook for
its look.
