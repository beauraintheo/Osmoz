# Flux

An interactive Flexbox reference: the place to check how a property behaves
when in doubt. It targets developers who already use Flexbox and need to
confirm a behavior fast, and stays clear enough for a beginner.

This section shows the `@osmoz/ui` components as Flux dresses them, in its
own theme. The toolbar's theme button switches every page of it.

## Identity

A quiet tool around a loud canvas: neutral surfaces, one teal accent, the
code in monospace. Every value below is read in the theme of this page.

## UX principles

Every design choice is checked against these. When two conflict, the first
listed wins.

1. **Instant feedback.** Every change shows on the canvas immediately.
2. **Recognition over recall.** Every value is visible with a diagram of its
   effect; nothing hides behind a dropdown.
3. **Direct manipulation.** Resize the container by dragging it, select an
   item by clicking it.
4. **User control.** Every change can be undone; nothing asks for
   confirmation.
5. **Standards.** CSS names are written exactly as in CSS; defaults are the
   browser's.
6. **Progressive disclosure.** Explanations are one hover or focus away.
7. **Accessible by default.** WCAG 2.2 AA and full keyboard use.
