# Button

A native `<button>` that triggers an action on the page. It adds two states the
native element lacks: **pending**, while the action runs, and **disabled but
focusable**, so a disabled action can still be reached and explained.

## Usage

<Guidelines>
  <Guideline preview={ButtonStories.Default} when="To run an action with a visible text label.">

## States

Each card renders its story and lists the attributes read on the rendered
`<button>`.

<States>
  <State of={ButtonStories.Default}>Focusable. Click runs.</State>
  <State of={ButtonStories.Disabled}>`disabled`. Skipped by Tab. Click blocked.</State>
  <State of={ButtonStories.FocusableWhenDisabled}>
    `disabled` and `focusableWhenDisabled`. Focusable. Click blocked.
  </State>
  <State of={ButtonStories.Pending}>`pending`. Focusable. Click blocked.</State>
</States>

A pending button stays focusable: the focus does not jump away while the
action runs, and assistive technologies announce it as busy.

## Keyboard

<Keyboard>
  <Key keys={["Tab"]}>Moves the focus to the button, unless it is `disabled`.</Key>
  <Key keys={["Enter", "Space"]}>Runs the action, unless the button is disabled or pending.</Key>
</Keyboard>

## Accessibility

- The role is the native `button`, so no ARIA role is added.
- `type` defaults to `"button"`, so a button inside a form never submits it by
  accident. Pass `type="submit"` on purpose.
- The accessible name is its text content. The app passes it from its catalog.
- Its content is free: an icon goes before or after the text, wrapped in a
  decorative `Icon`, so it is not read as part of the name.
- `aria-busy` and `aria-disabled` are set by the component: they are not props.

## Styling

The component has no class. Each app styles it in its own
`components/ui/button.tsx`, with a class for every state above: `disabled:`,
`aria-disabled:`, `aria-busy:`, `focus-visible:`. See each app's section of
this Storybook for its look.

The roles of the contract a styled button maps to, with their values in the
active theme:

<Tokens>
  <Token name="primary">Background of the main action.</Token>
  <Token name="primary-foreground">Its text and icon.</Token>
  <Token name="secondary">Background of a secondary action.</Token>
  <Token name="secondary-foreground">Its text and icon.</Token>
  <Token name="ring">Focus outline.</Token>
</Tokens>
