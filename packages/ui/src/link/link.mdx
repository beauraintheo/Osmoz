# Link

A native `<a>` that goes to another page or URL. It opens a new tab only
through its `newTab` prop, which then requires a `newTabHint`, so a link never
opens a tab without saying so.

## Examples

### New tab

`newTab` opens the destination in a new tab and requires `newTabHint`, added
after the text. The hint is part of the link's accessible name: "Read the docs
(new tab)". The app decides whether it is visible.

<Canvas of={LinkStories.NewTab} />

`target` is not a prop: `newTab` is the only way to open a new tab.

The component sets no `rel`. Current browsers apply `noopener` to
`target="_blank"` on their own, but not `noreferrer`: pass `rel` when the
destination must not receive the referrer.

## Accessibility

- The role is the native `link`, so no ARIA role is added.
- The accessible name is its text content, plus `newTabHint` when it opens a
  new tab. The app passes both from its catalog, punctuation included:
  `"(new tab)"`.

### Attributes

The component sets no `role`, `aria-*` or `data-*` attribute: a router link
adds its own, below.

### Styling

The component has no class and knows no router. Each app, in its own
`components/ui/link.tsx`:

- styles it, with a visible `focus-visible:` outline;
- gives `newTabHint` its look, usually inside an `sr-only` span;
- turns it into a router link with TanStack Router's `createLink`, so `to` is
  typed against its routes.

A router link marks the link of the current page with `aria-current="page"`
and `data-status="active"`: the app styles that state from either.
