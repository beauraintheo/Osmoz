# Separator

Base UI's [Separator](https://base-ui.com/react/components/separator), a
`<div role="separator">` that separates two groups of content. It exposes its
orientation as `aria-orientation` and `data-orientation` so each app can draw
it horizontal or vertical.

## Usage

<Guidelines>
  <Guideline preview={SeparatorStories.Default} when="Between two parts of the same block.">
    Horizontal.
  </Guideline>
  <Guideline preview={SeparatorStories.Vertical} when="Between two groups of controls in a bar.">
    Vertical, with `aria-hidden` when the layout already groups them.
  </Guideline>
</Guidelines>

Not every separation needs one:

- To space elements apart: use `gap` or `margin` in the layout.
- To separate sections that have a title: use a heading (`h2`…) inside a
  `<section>`, which already structures the content.
- To outline a block: use a `border` class on its container.

## Keyboard

None: the separator is never focusable.

## Accessibility

- Base UI sets `role="separator"` and `aria-orientation`, so a vertical
  separator is announced as such.
- A purely visual line, when the layout already shows the grouping, takes
  `aria-hidden`: screen readers skip it.
- `role` and `children` are not props: Base UI sets the role, and a separator
  has no content.

## API

The props of Base UI's Separator, minus `children`, `role` and `render`.
`className` and `style` take a value, not a function of the state:

## Styling

The component has no class. Each app, in its own
`components/ui/separator.tsx`:

- gives it its line color, like `border-border`: without it, the line takes
  `currentColor`;
- draws each orientation from its `orientation` prop. The `<div>` has no
  border of its own, so a horizontal separator needs `border-t`, and a
  vertical one `border-l` and `self-stretch`.

Pick those classes from the prop rather than with
`data-[orientation=vertical]:` variants: a variant's attribute selector
outweighs a plain class, so a caller's `className="h-5"` would lose to it. A
fixed height also needs `self-center`, since `self-stretch` with a set height
aligns the line to the start.

The role of the contract a styled separator maps to, with its value in the
Osmoz theme of this page, not of an app:

<Tokens>
  <Token name="border">Color of the line.</Token>
</Tokens>
